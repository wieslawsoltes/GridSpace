# GridSpace

A local-first spreadsheet workbench built with real Uno Platform, C# and SkiaSharp. Independent, reusable calculation, document, editing, file-format, chart, rendering and UI components power the same application on the web and desktop.

**Status:** 0.1.0-alpha.1, under active implementation. GridSpace is independently branded and is not Microsoft Excel. Excel-style interaction is the design target, not a claim of complete compatibility.

[Browser application](https://wieslawsoltes.github.io/GridSpace/) · [Builds](https://github.com/wieslawsoltes/GridSpace/actions)

The detailed architecture, feature support matrix, build instructions and validation record are maintained with the source.
